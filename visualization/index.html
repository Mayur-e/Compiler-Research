DOMAIN SEPARATION CONTRACT: Concrete runtime and static analysis operate on fundamentally distinct domains. Concrete execution observes one exact runtime path with hardware addresses (e.g. 0x...). Static analysis (A/B/C) computes sound abstract invariants over all possible paths with canonical NodeIDs (e.g. N1). Allocation site mappings are strictly a visualization bridge and do not alter HRA semantics.
